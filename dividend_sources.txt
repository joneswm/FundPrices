# Issuer sources of dividend dates (SPEC-011, #87).
#
# Yahoo gives the ex-date and amount of a past dividend and nothing else. A line
# here adds the issuer's own distribution table for one instrument: the daily
# run fetches it and fills in the pay date of every distribution, corrects an
# amount that differs from Yahoo's, adds the distributions Yahoo lacks, and
# turns a distribution the issuer has announced into a "declared" row in
# data/dividends_upcoming.csv.
#
# Format: <identifier>,<source>,<source-id>
#
#   identifier  an identifier published in funds.txt (lookup id or alias). A fund
#               priced from the FT may be named too: its dividends come from here
#   source      the issuer, or its exchange partner, that states the pay date:
#                 IS  iShares UK (www.ishares.com/uk), allowed by its robots.txt
#                 IV  Invesco (the fund-data API its product pages call)
#                 SS  SSGA (the SPDR EMEA historical-distributions workbook)
#                 Q4  a Q4 Inc investor-relations site (the company's own feed)
#                 ET  etnet (HKEX Information Services partner; cash dividends)
#   source-id   what names the instrument at that source:
#                 IS  the product id in the fund page's URL,
#                     https://www.ishares.com/uk/individual/en/products/<id>/...
#                     One id per share class: take the one of the distributing
#                     class that matches the instrument (GBP hedged, USD, ...). A
#                     class that accumulates has no table and fails the fetch
#                 IV  the fund's CUSIP (the API answers nothing for a ticker)
#                 SS  the fund's ISIN; one download serves every SS line
#                 Q4  <ir host>/<exchange MIC>; the ticker is the identifier
#                 ET  the HK stock code without leading zeros (0639.HK is 639)
#
# One line per instrument. iShares product ids come from
# https://www.ishares.com/uk/product-sitemap.xml; the page names the ISIN, and
# the ex-dates and amounts of a right id equal Yahoo's. See
# docs/research/dividend_pay_date_sources.md and specs/012-pay-date-sources/ for
# how each source was found and what it costs.
