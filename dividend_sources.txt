# Issuer sources of dividend dates (SPEC-011, #87).
#
# Yahoo gives the ex-date and amount of a past dividend and nothing else. A line
# here adds the issuer's own distribution table for one instrument: the daily
# run fetches it and fills in the pay date of every distribution, corrects an
# amount that differs from Yahoo's, adds the distributions Yahoo lacks, and
# turns a distribution the issuer has announced into a "declared" row in
# data/dividends_upcoming.csv.
#
# Format: <identifier>,<source>,<source-id>
#
#   identifier  an identifier published in funds.txt (lookup id or alias). A fund
#               priced from the FT may be named too: its dividends come from here
#   source      IS: iShares UK (www.ishares.com/uk), allowed by its robots.txt
#   source-id   for IS, the product id in the fund page's URL,
#               https://www.ishares.com/uk/individual/en/products/<id>/...
#               One id per share class: take the one of the distributing class
#               that matches the instrument (GBP hedged, USD, ...). A class that
#               accumulates has no table and fails the instrument's fetch
#
# One line per instrument. Product ids come from
# https://www.ishares.com/uk/product-sitemap.xml; the page names the ISIN, and
# the ex-dates and amounts of a right id equal Yahoo's. See
# docs/research/dividend_pay_date_sources.md for why only the iShares funds are
# here: QQQ, GLTL.L, KNSL and 0639.HK have no source that is both reachable and
# allowed.
